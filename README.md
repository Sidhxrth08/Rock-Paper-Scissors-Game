# 🪨 Rock, Paper, Scissors Game

A simple **Rock, Paper, Scissors** game made using **Python**.
The player chooses Rock, Paper, or Scissors, and the computer randomly selects its choice. The program then decides the winner.

## 🎮 Features

* 🪨 Rock
* 📄 Paper
* ✂️ Scissors
* 🎲 Random computer choice
* 🏆 Win, lose, and tie detection
* ⚠️ Invalid input handling

## 🛠️ Technologies Used

* **Python**
* **Random Module**



## 🎯 How to Play

When the game starts, enter one of these choices:

* rock
* paper
* scissors


* The computer will randomly choose one as well.

### Winning Rules

| Player      | Computer    | Result           |
| ----------- | ----------- | ---------------- |
| Rock        | Scissors    | 🏆 You Win       |
| Paper       | Rock        | 🏆 You Win       |
| Scissors    | Paper       | 🏆 You Win       |
| Same Choice | Same Choice | 🤝 Tie           |
| Otherwise   | —           | 💻 Computer Wins |
